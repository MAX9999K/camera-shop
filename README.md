# Camera Shop — โค้ด Python ไฟล์เดียว (`camera_shop.py`)

## วิธีรัน
    python -m pip install -r requirements.txt     (ทำครั้งเดียว)
    python camera_shop.py                         รันทั้ง 2 เว็บ (Ctrl+C เพื่อปิด)
    python camera_shop.py shop                    เฉพาะเว็บร้านค้า
    python camera_shop.py admin                   เฉพาะเว็บ Admin

| เว็บ | ที่อยู่ |
|---|---|
| ร้านค้า (ลูกค้า) | http://127.0.0.1:5000 |
| ผู้ดูแลระบบ | http://127.0.0.1:5001 (รหัสเริ่มต้น `admin1234`) |

ต้องวาง `camera_shop.py` ไว้ข้างโฟลเดอร์ `templates_shop/`, `templates_admin/`, `static/` (หน้าตาเว็บเป็นไฟล์ HTML)
ตั้งค่า QR รับเงิน: Admin → "ตั้งค่า PromptPay" (ใส่ PromptPay ID เพื่อสร้าง QR อัตโนมัติ หรืออัปโหลดรูป QR ของร้านเอง)

## แผนผังไฟล์ (อ่านจากบนลงล่าง ส่วนล่างเรียกใช้ส่วนบน)
| ส่วนที่ | เนื้อหา |
|---|---|
| 1-9 | เครื่องมือพื้นฐาน: error, config, เงิน(สตางค์), ตรวจข้อมูล, ความปลอดภัย, QR PromptPay, อัปโหลดรูป, ฐานข้อมูล |
| 10 | ตั้งค่า Flask ที่ 2 เว็บใช้ร่วมกัน (session, CSRF) |
| 11-16 | SERVICE = ตรรกะของร้าน: ตั้งค่า, สินค้า, สมาชิก, ส่วนลด, ตะกร้า, **คำสั่งซื้อ (Transaction)** |
| 17 | เว็บร้านค้า (ลูกค้า) |
| 18 | เว็บผู้ดูแลระบบ (Admin) |
| 19 | จุดเริ่มต้นโปรแกรม |

ค้นหาแต่ละส่วนในไฟล์ด้วย `ส่วนที่ N:` (เช่น Ctrl+F "ส่วนที่ 16")

## ข้อจำกัดที่ควรบอกผู้เรียน
- ระบบไม่รู้เองว่าลูกค้าโอนเงินแล้ว → Admin ตรวจแล้วกด "ยืนยันรับเงิน"
- ออเดอร์จะตัดสต็อกทันทีที่สั่ง หากยกเลิกออเดอร์ที่ยังรอชำระ ระบบจะคืนสต็อกให้อัตโนมัติ
- หากใช้รูป QR ที่อัปโหลดเอง รูปนั้นอาจไม่ได้ฝังยอดเงินอัตโนมัติ ลูกค้าต้องตรวจยอดก่อนโอน
- ใบเสร็จเป็นเอกสารประกอบโครงงาน ไม่ใช่ใบกำกับภาษี
- การชำระด้วยบัตรเป็นการจำลอง

## เพิ่มรูปและรายละเอียดสินค้า (ทำที่เว็บ Admin)
- **สินค้าใหม่:** เมนู "สินค้า/สต็อก" → ฟอร์ม "เพิ่มสินค้าใหม่" ด้านล่าง เลือกรูปได้ **สูงสุด 5 รูป** พร้อมกัน (กด Ctrl หรือ Shift ค้างเพื่อเลือกหลายไฟล์) รูปแรกที่เลือกคือรูปหลัก
- **สินค้าที่มีอยู่แล้ว:** กดปุ่ม "แก้ไข รูป/รายละเอียด" ท้ายแถวสินค้า
  - เพิ่มรูปใหม่ (รวมแล้วไม่เกิน 5 รูป)
  - ติ๊ก "ลบรูปนี้" เพื่อลบรูป (ไฟล์ถูกลบออกจากเครื่องด้วย)
  - เลือก "รูปหลัก" เพื่อเปลี่ยนรูปที่แสดงบนการ์ดสินค้า
  - ถ้าครบ 5 รูปแล้วจะเพิ่มได้เท่าจำนวนที่ติ๊กลบ
- รูป: png, jpg, jpeg, webp, gif รูปละไม่เกิน 4 MB (ใช้รูปจัตุรัสจะสวยที่สุด)
- รายละเอียด: ไม่เกิน 1,000 ตัวอักษร ขึ้นบรรทัดใหม่ได้
- ลูกค้ากดปุ่ม "ดูด่วน" บนการ์ดสินค้าเพื่อดูรูปทั้งหมด (กดรูปย่อเพื่อสลับ) และรายละเอียด
- ปรับจำนวนรูปสูงสุดได้ที่ `MAX_IMAGES_PER_PRODUCT` ใน config
- รายละเอียดของสินค้าตัวอย่าง 9 รายการเป็นข้อความตัวอย่าง ควรแก้เป็นสเปกจริงก่อนใช้งาน
